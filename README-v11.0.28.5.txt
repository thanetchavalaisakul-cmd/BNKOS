BNK School OS v11.0.28.5 — Student Import Reconciliation

Hotfix / enhancement for ระบบบัญชีรายชื่อนักเรียน

สิ่งที่เพิ่ม
- เก็บผลเปรียบเทียบการนำเข้า Excel เป็นประวัติถาวร
- แสดงนักเรียนที่ “มีในระบบ แต่ไม่อยู่ในไฟล์” อย่างชัดเจน
- นักเรียนที่ไม่พบในไฟล์จะไม่ถูกลบหรือเปลี่ยนสถานะอัตโนมัติ
- หลัง Import สามารถตรวจสอบทีละคนและเลือกสถานะ: คงสภาพ, ย้ายออก, ไม่เรียนต่อ, ลาออก/พ้นสภาพ, เกินเกณฑ์, จบการศึกษา, เสียชีวิต, ข้อมูลซ้ำ/ไม่มีตัวตน, อื่น ๆ
- เก็บผู้ยืนยัน เวลา เหตุผล และหมายเหตุ เพื่อการตรวจสอบย้อนหลัง
- เก็บสรุปต่อรอบ: รายชื่อเดิม / ในไฟล์ / ไม่พบ / เพิ่มใหม่ / เปลี่ยนห้อง
- เมื่อยืนยันสถานะ ระบบเปลี่ยนเฉพาะ enrollment ของภาคเรียนนั้น และเก็บประวัตินักเรียนเดิมไว้
- ใช้ระบบ Import แบบ chunk และพัก Realtime จาก v11.0.28.4 ต่อเนื่อง
