# BNK School OS v11.0.25 — Student Card Certifier

เพิ่มระบบผู้รับรองบัตรนักเรียนแบบ Snapshot เพื่อให้บัตรที่ออกแล้วคงผู้รับรองเดิม แม้มีการเปลี่ยนผู้อำนวยการภายหลัง

## ฟังก์ชันใหม่
- ปุ่ม `ตั้งค่าผู้รับรองบัตร` ในระบบบัตรนักเรียน
- กำหนดชื่อผู้รับรองและตำแหน่งได้
- อัปโหลดลายเซ็น PNG พื้นหลังโปร่งใส
- เมื่อออกบัตร ระบบ Snapshot ชื่อ/ตำแหน่ง/ไฟล์ลายเซ็นลงในบัตรแต่ละใบ
- เปลี่ยนผู้รับรองในอนาคตไม่กระทบบัตรที่เคยออกแล้ว
- บัตรใหม่จะออกไม่ได้จนกว่าจะตั้งค่าผู้รับรองครบ
- บนบัตรจะแสดง `ผู้รับรองบัตร` + ลายเซ็น + ตำแหน่งผู้รับรอง

## สิทธิ์ตั้งค่า
Super Admin และหัวหน้ากลุ่มงานบริหารวิชาการ ตามมาตรฐานสิทธิ์ Student Master เดิม
